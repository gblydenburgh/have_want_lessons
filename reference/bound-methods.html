Bound methods and self

What r1.show_version() does, in two steps, and the errors you get when the two sides don't match.

The two steps

  1. Read r1.show_version. Attribute lookup finds the function on the class. Read through an instance, it comes back as a bound method: an new object that refers to the function and r1. The method is the function; the bound method is a separate object pointing at it.
  2. Call it with (). Python calls the function with the instance put in front of the arguments you wrote. The instance lands in the first parameter, which by convention is named self.

Through the instance or through the class

ExpressionWhat you get
r1.show_versionBound method (function + r1). Nothing runs.
r1.show_version()The function, called with r1 first.
IosRouter.show_versionThe plain function. No instance.
IosRouter.show_version(r1)Same as r1.show_version().
handlers = {"merged": sw1.merged}Stores the bound method; calling it later still passes sw1.

Reading the errors

MessageUsual cause
f() takes 0 positional arguments but 1 was givenThe def line has no self; the instance has nowhere to go.
f() takes 1 positional argument but 2 were givenSame, with one argument you wrote. The count includes the instance.
f() missing 1 required positional argument: 'self'Called through the class (or a function stored on an instance): nothing was bound.
'str' object is not callableData stored on the instance under the method's name hides the method.
mypy: could always be true in boolean contextif x.method: with no (). A bound method is always true.

No brackets in real code isn't always a bug. If the def has @property above it, reading the attribute runs the method (route step 6).

Check it in Python

r1.show_version                    # <bound method IosRouter.show_version of …>
IosRouter.show_version             # <function IosRouter.show_version at …>
m = r1.show_version; m()           # store it, call it later

Layer 3. Functions are descriptors: they have a __get__ method. When lookup finds one on the class, Python calls function.__get__(r1, IosRouter), which returns the bound method. m.__func__ is the function and m.__self__ is the instance. Each read builds a new bound method (is is false, == is true). A function stored on an instance isn't bound.
